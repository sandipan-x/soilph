# SoilPH

Soil pH calculator: find exactly how much lime or sulfur your garden needs to hit its target pH, with crop preferences and retest dates. Free tool.

## Features
- Lime and sulfur rate calculator from current pH, target pH, and bed area
- Crop pH preference table with one-tap target presets
- Soil-type-aware sulfur rates plus an automatic retest-date planner
